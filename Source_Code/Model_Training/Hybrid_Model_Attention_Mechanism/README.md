# 🧠 Hybrid Model Training With Attention Mechanism

This folder contains the implementation of the hybrid model with an attention mechanism, trained using varying amounts of real-world vibration data to evaluate its performance.

## ⚙️ Model Training

The hybrid model is trained with an attention mechanism using real-world vibration data in different quantities.

### Key Features
- Hybrid model architecture with an attention mechanism.
- Frequency-domain vibration signal processing.
- Training with varying amounts of real-world data.
- Model checkpoint saving at different training stages.
- Performance evaluation across different data quantities.

## 📊 Model Analysis

The trained models are evaluated using real-world vibration signals to analyse the effect of varying real-data availability on model performance.

### Analysis Includes
- Overall accuracy comparison.
- Accuracy improvement analysis.
- Per-class accuracy trends.
- Confusion matrices.
- Per-class detailed metrics.
- Performance comparison across different real-data quantities.

## 📁 Files

- `Model Training AM Real Data.py` – Hybrid model training implementation.
- `AM Analysis Real Data.py` – Model evaluation and analysis implementation.

## 🔄 Workflow

1. Prepare real-world vibration data.
2. Train the hybrid model with the attention mechanism using different quantities of real data.
3. Save trained models and checkpoints.
4. Analyse model performance using real-world test signals.
5. Compare results across different real-data quantities.

**Note:** This implementation focuses on analysing the effect of varying real-world data availability on the hybrid model with an attention mechanism.
