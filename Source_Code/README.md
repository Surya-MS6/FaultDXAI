# 💻 Source Code

Python implementation of the FaultDXAI framework, covering vibration signal processing, synthetic data generation and deep learning-based fault classification.

## ⚙️ Implementation Modules

| Module | Description |
|---|---|
| 🧪 Synthetic Signal Generation | Generation of fault-specific vibration signals |
| 📊 Data Augmentation | Signal variation and dataset enhancement |
| 📡 Signal Processing | FFT transformation and normalization |
| 🧠 1D CNN | Deep feature extraction and fault classification |
| 🎯 Attention Mechanism | Frequency-dependent feature weighting |
| 🔄 Domain Adaptation | Synthetic-to-real data integration |
| 📈 Model Evaluation | Accuracy and classification performance analysis |

## 🛠️ Tech Stack

- Python
- TensorFlow & Keras
- NumPy
- SciPy
- Matplotlib

## 📂 Code Organisation

Python scripts will be organised according to their functionality, making individual processing stages easier to understand and maintain.
