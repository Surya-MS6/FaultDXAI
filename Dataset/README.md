# 📂 Dataset

Vibration signal data used for rotating machinery fault diagnosis.

### ⚙️ Dataset Overview

- **Fault Classes:** Normal, Misalignment, Looseness and Unbalance.
- **Sensors:** 4 accelerometer channels.
- **Sampling Frequency:** 25 kHz.
- **Samples per Signal:** 25,000.
- **Data Format:** NumPy (`.npy`).

### 📊 Dataset Contents

| Category | Description |
|---|---|
| Normal | Healthy operating condition |
| Misalignment | Shaft alignment fault |
| Looseness | Mechanical looseness |
| Unbalance | Rotor mass imbalance |

### 🔬 Data Processing

- Synthetic vibration signal generation.
- Signal augmentation.
- FFT-based frequency analysis.
- Signal normalization.
