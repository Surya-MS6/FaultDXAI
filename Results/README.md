# 📊 Experimental Results

Performance evaluation of FaultDXAI using real vibration signals under different model configurations.

## 📈 Classification Performance

| Model Configuration | Accuracy |
|---|---:|
| Baseline 1D CNN | 84.32% |
| Attention-Based 1D CNN | 88.89% |
| Attention + 30 Real Samples | 91.06% |
| Attention + 70 Real Samples | 92.31% |

## 🔍 Evaluation Metrics

The classification performance is analysed using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
