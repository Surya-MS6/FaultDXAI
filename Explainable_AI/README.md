# 🔍 Explainable AI

Grad-CAM-based interpretability for understanding the feature activations influencing rotating machinery fault classification.

## 🧠 Grad-CAM Analysis

Grad-CAM (Gradient-weighted Class Activation Mapping) is used to highlight the regions of the learned feature representations that contribute to the model's predicted fault class.

## ⚙️ Interpretation Workflow

1. Input vibration signal.
2. Deep feature extraction through 1D CNN.
3. Gradient-based activation analysis.
4. Generation of Grad-CAM visualizations.
5. Interpretation of fault-relevant features.

## 📊 Visualization Categories

| Analysis | Purpose |
|---|---|
| Activation Maps | Visualize important learned features |
| Class-wise Analysis | Examine feature responses for different fault conditions |
| Prediction Interpretation | Understand features influencing model decisions |

## 📁 Visualization Storage

Grad-CAM plots and related interpretability outputs will be maintained in this directory.
