# 🧠 Trained Model – Hybrid Model With Attention Mechanism

## 📌 Overview
This folder contains the trained hybrid fault diagnosis model integrated with an attention mechanism. The model is developed to improve fault classification by combining the hybrid learning approach with attention-based feature extraction.

## ⚙️ Model Architecture
- Hybrid deep learning architecture.
- Integrated attention mechanism.
- Frequency-domain vibration signal processing.
- Designed for four fault classes.

## 📊 Model Details
- **Model Type:** Hybrid Model with Attention Mechanism
- **Input Domain:** Frequency Domain
- **Fault Classes:** Normal, Misalignment, Looseness, Unbalance
- **Signal Sampling Frequency:** 25 kHz
- **Accelerometer Channels:** 4

## 📁 Model File
This folder contains the trained hybrid model and its associated checkpoint files.

## 🔄 Usage
The trained model can be loaded and used for fault classification and evaluation.

The corresponding training and analysis scripts are available in:

`Source_Code/Model_Training/Hybrid_Model_With_Attention/`

## 🎯 Purpose
The purpose of this model is to evaluate the hybrid architecture with attention and study its performance when trained using varying amounts of real-world vibration data.
